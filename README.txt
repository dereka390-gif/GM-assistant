GM ASSISTANT MVP

LOCAL TEST
1. Unzip the folder on a Mac or Windows computer.
2. Open Terminal or Command Prompt inside the folder.
3. Run: python3 -m http.server 8000
   Windows may use: py -m http.server 8000
4. Open http://localhost:8000

IPHONE/IPAD INSTALL
1. Put the files on a web host.
2. Open the site in Safari.
3. Share > Add to Home Screen.

ANDROID INSTALL
1. Open the site in Chrome.
2. Menu > Install app or Add to Home screen.

IMPORTANT
- This prototype stores data only in that browser using localStorage.
- Export a JSON backup regularly.
- Do not publish the complete proprietary OSM in a public repository.
- The Ask OSM screen contains only three sample references.
